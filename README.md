This project is a web-based marketplace platform where users can create accounts, log in, and publish ads.

Built with:

Frontend: React
Backend: Node.js / Express
Database: PostgreSQL
Features
User registration and login
Create and manage advertisements
API communication between frontend and backend
PostgreSQL database integration
Rate limiting for API and database protection
Security

The project uses rate limiting to:

Prevent spam
Protect against brute force attacks
Reduce the risk of database overload
